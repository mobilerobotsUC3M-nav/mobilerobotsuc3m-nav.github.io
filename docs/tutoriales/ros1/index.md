# Bloque ROS 1: Ubuntu 20.04 + Noetic

<span class="bloque bloque-ros1">ROS 1 · Ubuntu 20.04 + Noetic</span>

!!! info "Este bloque usa Ubuntu 20.04 y ROS 1 Noetic"
    Es la configuración de los **robots del grupo** (TurtleBot 2 y ADAM). Si tu trabajo es con
    ellos, este es tu bloque. Todo lo que hay aquí asume **Ubuntu 20.04** y **ROS Noetic**:
    no sirve para Ubuntu 24.04 ni para ROS 2.

Síguelos en este orden:

1. [Instalar Ubuntu 20.04 junto a Windows](ubuntu20.md): si tu ordenador tiene Windows.
2. [Instalar ROS Noetic](instalar-noetic.md): instalación, espacio de trabajo `catkin_ws` y primer nodo.
3. [ROS en varios ordenadores](red.md): `ROS_MASTER_URI`, `ROS_IP`, hosts y SSH, para conectarte a un robot.
4. [Stack de navegación](navegacion.md): mapas, localización y `move_base`, en simulación.
5. [Cámara RealSense](realsense.md): la cámara de profundidad en Python y en ROS 1.

Después, mira la página de [tu robot](../../robots/index.md).
