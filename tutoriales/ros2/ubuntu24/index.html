    Instalar Ubuntu 24.04 junto a Windows (arranque dual)¶

    ROS 2 · Ubuntu 24.04 + Jazzy

    Al terminar tendrás Ubuntu 24.04 y Windows en el mismo ordenador. Al encenderlo aparecerá un menú para elegir cuál arrancar. Es la forma recomendada de trabajar con ROS 2 Jazzy: en una máquina virtual, Gazebo va lento y las cámaras USB 3 dan problemas.

    Antes de nada: haz una copia de seguridad

    Vas a modificar las particiones del disco. Si se sigue el tutorial no se pierde nada, pero un error puede borrar Windows y tus archivos. Copia lo importante a un disco externo o a la nube antes de empezar.

    Necesitas:

    • Un USB de 8 GB o más (se borrará entero).
    • Al menos 80–100 GB libres en el disco. ROS, Gazebo, rosbags y datasets ocupan mucho; con menos de 50 GB te quedarás sin espacio.
    • El portátil enchufado y 1–2 horas.
    • Tu clave de recuperación de BitLocker, si el disco está cifrado (ver paso 1.2).

    Si algo no coincide con lo que describe el tutorial, para y pregunta

    Cada ordenador es un poco distinto. Es mucho mejor preguntar en el grupo que seguir adelante a ciegas en el paso de las particiones.

    1. Comprobaciones en Windows¶

    1.1. Modo de arranque (UEFI)¶

    1. Pulsa Win+R, escribe msinfo32 y pulsa Enter.
    2. En Resumen del sistema, busca Modo de BIOS. Debe poner UEFI.

    Casi todos los ordenadores de los últimos diez años usan UEFI. Si pone Heredado (Legacy), consúltalo antes de seguir: el proceso cambia.

    1.2. BitLocker y cifrado del dispositivo¶

    Muchos portátiles con Windows 11 traen el disco cifrado de fábrica. Al tocar el arranque, Windows puede pedirte la clave de recuperación de 48 dígitos, y si no la tienes, no podrás volver a entrar en Windows.

    1. Abre Configuración → Privacidad y seguridad → Cifrado del dispositivo (o busca "BitLocker" en el menú Inicio).
    2. Si el cifrado está activado, guarda la clave de recuperación: está en aka.ms/myrecoverykey entrando con tu cuenta de Microsoft. Apúntala en papel o en el móvil, no solo en el propio portátil.
    3. En Panel de control → Cifrado de unidad BitLocker, pulsa Suspender protección para la unidad C:. Se reactiva sola tras unos reinicios.

    1.3. Desactivar el inicio rápido¶

    El "inicio rápido" de Windows no apaga del todo el ordenador: deja el disco en un estado semihibernado que Ubuntu no puede tocar con seguridad.

    1. Panel de control → Opciones de energía → Elegir el comportamiento de los botones de inicio/apagado.
    2. Pulsa Cambiar la configuración actualmente no disponible.
    3. Desmarca "Activar inicio rápido" y guarda.

    1.4. Controlador de disco (Intel RST / VMD)¶

    Algunos portátiles con procesador Intel traen el disco configurado en modo RST o VMD, y el instalador de Ubuntu no verá el disco.

    Pulsa con el botón derecho en Inicio → Administrador de dispositivos → despliega Controladoras de almacenamiento. Si aparece algo con "RST" o "VMD", avisa a tu tutor/a antes de seguir: hay que cambiar una opción de la BIOS siguiendo un procedimiento concreto para que Windows siga arrancando.

    2. Hacer hueco para Ubuntu¶

    Vamos a encoger la partición de Windows para dejar espacio libre.

    1. Pulsa Win+X → Administración de discos.
    2. Haz clic derecho en la partición (C:) → Reducir volumen.
    3. En Tamaño del espacio que desea reducir, en MB, escribe el espacio para Ubuntu. Para 100 GB: 102400.
    4. Pulsa Reducir.

    Aparecerá un bloque negro marcado como No asignado. Déjalo así: no crees ninguna partición en él, lo hará el instalador de Ubuntu.

    ¿Windows no deja reducir tanto como quieres?

    Windows no puede mover algunos archivos de sistema. Libera espacio (vacía la papelera, desinstala programas que no uses) y vuelve a intentarlo. Si aun así no deja, pregunta.

    3. Preparar el USB de instalación¶

    1. Descarga la imagen de escritorio más reciente de Ubuntu 24.04 LTS (Desktop image, un archivo ubuntu-24.04.X-desktop-amd64.iso de unos 6 GB) desde releases.ubuntu.com/24.04.

      Asegúrate de que es la 24.04

      En la web principal de Ubuntu el botón de descarga ofrece la versión más nueva (26.04). Para ROS 2 Jazzy necesitas la 24.04: descárgala desde el enlace de arriba.

      1. Descarga Rufus desde rufus.ie (la versión portable no necesita instalación).
      2. Conecta el USB, abre Rufus y configura:
      Opción Valor
      Dispositivo Tu USB (comprueba que es el correcto: se borrará)
      Elección de arranque SELECCIONAR → la ISO de Ubuntu
      Esquema de partición GPT
      Sistema destino UEFI (no CSM)

    2. Pulsa EMPEZAR. Si pregunta por el modo de escritura, elige Modo Imagen ISO (recomendado). Si pregunta por descargar archivos adicionales, acepta.

    4. Arrancar desde el USB¶

    Con el USB conectado, reinicia el ordenador desde el menú de arranque:

    1. Configuración → Sistema → Recuperación → Inicio avanzado → Reiniciar ahora.
    2. En la pantalla azul, elige Usar un dispositivo y selecciona el USB.

    Apaga el ordenador, enciéndelo y pulsa repetidamente la tecla del menú de arranque:

    Fabricante Tecla habitual
    Lenovo, Dell, Acer F12
    HP F9 (o Esc y luego F9)
    ASUS Esc o F8
    MSI F11

    En el menú, elige la entrada del USB que empiece por UEFI.

    Aparecerá un menú negro: elige Ubuntu (o Try or Install Ubuntu).

    Secure Boot

    Ubuntu 24.04 arranca con Secure Boot activado, así que en principio no hay que tocar la BIOS. Si el USB no arranca de ninguna forma, entra en la BIOS y desactiva Secure Boot temporalmente.

    5. Instalar Ubuntu¶

    Ubuntu 24.04 trae un instalador nuevo. Los nombres de los botones pueden variar un poco según la versión exacta de la imagen, pero el orden es este:

    1. Idioma: Español → Siguiente.
    2. Accesibilidad: sin cambios → Siguiente.
    3. Teclado: Español → Español.
    4. Conexión a internet: conéctate a la wifi o por cable (para descargar drivers).
    5. Probar o instalar: elige Instalar Ubuntu.
    6. Tipo de instalación: Instalación interactiva.
    7. Aplicaciones: Selección predeterminada es suficiente.

    8. Optimizar el ordenador: marca Instalar software de terceros para hardware de gráficos y wifi y Descargar e instalar soporte para formatos multimedia adicionales.

      Si tienes Secure Boot activado, puede pedirte que inventes una contraseña de Secure Boot. Apúntala: la necesitarás una única vez en el primer reinicio (ver paso 6).

    9. ¿Cómo quieres instalar Ubuntu? Elige Instalación manual. Es la opción que te deja controlar exactamente qué se toca.

      No elijas 'Borrar el disco e instalar Ubuntu'

      Borra Windows y todos tus archivos. Tampoco actives el cifrado del disco ni ZFS en las opciones avanzadas: complican la recuperación si algo falla.

      ¿Y 'Instalar Ubuntu junto a Windows Boot Manager'?

      También funciona, y usa el espacio libre que dejaste en el paso 2. Pero la instalación manual te enseña exactamente qué se va a tocar, así que es la que recomendamos.

    Las particiones¶

    Verás la lista de particiones del disco (nvme0n1p1, nvme0n1p2... o sda1...). Las de Windows están en formato ntfs y hay una pequeña de tipo fat32 o efi, que es la del arranque. No toques ninguna de ellas.

    1. Arriba, en Dispositivo para instalar el gestor de arranque, deja el disco entero donde está Windows (por ejemplo nvme0n1, sin número de partición al final).
    2. Selecciona la línea Espacio libre (debe tener el tamaño que reservaste en el paso 2).

    3. Pulsa + y rellena:

      Campo Valor
      Tamaño Todo el disponible (el que sale por defecto)
      Usado como Ext4
      Punto de montaje /

    4. Pulsa Aceptar y luego Siguiente.

    No hace falta crear partición de intercambio (swap): Ubuntu 24.04 crea un archivo de intercambio automáticamente.

    Datos finales¶

    • Zona horaria: Madrid.
    • Tu nombre, nombre del equipo, usuario y contraseña. Para el nombre del equipo usa algo corto, en minúsculas y sin espacios ni tildes (por ejemplo portatil-maria): es el nombre con el que tu ordenador se identificará en la red del robot (ver ROS 2 en varios ordenadores).

    Antes de empezar, el instalador muestra un resumen ("Listo para instalar").

    Revisa el resumen antes de confirmar

    En el apartado de particiones solo debe aparecer una partición nueva ext4 montada en / que se va a formatear. Si aparece cualquier partición ntfs que se vaya a formatear o borrar, pulsa Atrás y revisa.

    Pulsa Instalar. Cuando termine, pulsa Reiniciar ahora y quita el USB cuando te lo pida.

    6. Primer arranque¶

    La pantalla azul de Secure Boot (MOK)¶

    Si en la instalación creaste una contraseña de Secure Boot, al reiniciar aparecerá una pantalla azul en inglés (MOK management). Tienes unos segundos para pulsar una tecla:

    1. Enroll MOK → Continue → Yes.
    2. Escribe la contraseña de Secure Boot que inventaste.
    3. Reboot.

    Si la pantalla se pasa sin que hagas nada, el ordenador arranca igual pero los drivers de la gráfica NVIDIA no se cargarán. Se puede repetir el proceso más tarde; pregunta.

    El menú de arranque (GRUB)¶

    A partir de ahora, al encender verás un menú:

    • Ubuntu → arranca Ubuntu (opción por defecto).
    • Windows Boot Manager → arranca Windows.

    ¿Arranca directamente Windows sin mostrar el menú?

    Entra en la BIOS (normalmente F2 o Del al encender) y en el orden de arranque (Boot order) pon ubuntu por delante de Windows Boot Manager.

    7. Después de instalar¶

    Abre una terminal (Ctrl+Alt+T) y ejecuta:

    # Actualizar el sistema
sudo apt update && sudo apt upgrade -y

# Drivers de la tarjeta gráfica (si tienes NVIDIA)
ubuntu-drivers devices
sudo ubuntu-drivers install

# Que Windows y Ubuntu no se peleen por la hora
timedatectl set-local-rtc 1 --adjust-system-clock

    Reinicia y ya puedes seguir con Instalar ROS 2 Jazzy.

    ¿Por qué el último comando?

    Windows y Linux interpretan de forma distinta el reloj interno del ordenador. Sin este ajuste, cada vez que cambias de sistema la hora aparece desplazada una o dos horas.

    Problemas frecuentes¶

    El USB no aparece en el menú de arranque

    Comprueba que en Rufus elegiste GPT y UEFI (no CSM). Prueba otro puerto USB. En la BIOS, desactiva temporalmente Fast Boot y, si sigue sin aparecer, Secure Boot.

    El instalador no muestra el disco o solo ve el USB

    El disco está en modo Intel RST / VMD (paso 1.4). No sigas: pregunta.

    Al volver a Windows pide la clave de recuperación de BitLocker

    Es la clave que guardaste en el paso 1.2 (aka.ms/myrecoverykey). Introdúcela y Windows arrancará con normalidad.

    No funciona la wifi en Ubuntu

    Las imágenes recientes de Ubuntu 24.04 traen un kernel nuevo con soporte para casi todas las tarjetas wifi. Si aun así no funciona, conéctate por cable (o comparte internet desde el móvil por USB), actualiza el sistema con sudo apt update && sudo apt full-upgrade y reinicia. Si sigue sin funcionar, pregunta en el grupo.

    La pantalla se queda negra al arrancar el USB o Ubuntu

    Suele ser la gráfica NVIDIA. En el menú negro del USB (o en GRUB), pon el cursor sobre Ubuntu, pulsa E, busca la palabra quiet splash y añade detrás nomodeset. Pulsa F10 para arrancar. Después de instalar, instala los drivers (paso 7).
